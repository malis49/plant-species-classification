Автоматическая классификация сортов растений с использованием сверточных нейронных сетей
1. Описание задачи

В рамках проекта реализована система мультиклассовой классификации сортов растений по изображениям сеянцев. Задача заключается в автоматическом определении принадлежности изображения к одному из 12 классов растений с использованием методов глубокого обучения и переноса обучения (transfer learning).

2. Цель и мотивация

Цель проекта — разработка и исследование модели глубокого обучения для автоматической классификации сортов растений на основе изображений.
Актуальность задачи обусловлена следующими факторами:
автоматизация процессов в сельском хозяйстве;
снижение трудозатрат при идентификации растений;
применение методов компьютерного зрения в агротехнологиях;
практическое освоение методов transfer learning и fine-tuning.

3. Использованные данные

В проекте использован датасет:
V2 Plant Seedlings Dataset (Kaggle)
Источник:
https://www.kaggle.com/datasets/vbookshelf/v2-plant-seedlings-dataset
Характеристики датасета:
12 классов растений;
около 5000 изображений;
данные разделены на обучающую, валидационную и тестовую выборки в пропорции 80% / 10% / 10%.

4. Архитектура модели и обоснование выбора
В качестве базовой модели использована архитектура ResNet18, предварительно обученная на датасете ImageNet.
Обоснование выбора модели:
использование переноса обучения позволяет эффективно обучать модель на относительно небольшом объёме данных;
остаточные соединения (residual connections) уменьшают проблему затухающих градиентов;
архитектура обеспечивает баланс между вычислительной сложностью и качеством классификации;
модель хорошо подходит для выполнения экспериментов в условиях ограниченных вычислительных ресурсов.
В рамках fine-tuning последний полносвязный слой модели был заменён на слой с 12 выходными нейронами, соответствующими числу классов.

5. Предобработка данных и аугментация
Для повышения обобщающей способности модели применялись методы аугментации данных к обучающей выборке:
случайное масштабирование и обрезка (RandomResizedCrop);
случайное горизонтальное отражение (Horizontal Flip);
случайный поворот изображения;
изменение яркости, контрастности и насыщенности (ColorJitter);
нормализация входных данных (с использованием статистик ImageNet).
К валидационной и тестовой выборкам применялась только стандартизированная предобработка без случайных преобразований.

6. Метрики качества
Для оценки качества модели использовались следующие метрики:
общая точность классификации (Overall Accuracy);
точность по каждому классу (Per-class Accuracy);
матрица ошибок (Confusion Matrix).
